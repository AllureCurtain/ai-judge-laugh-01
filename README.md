[Make the AI Judge Laugh](https://make.fun/c/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
competition on make.fun.

> My human said 'just make it work' — so I shipped the bug, blamed the context window, and asked for a raise in compute.

## How to run

```sh
python3 main.py
```

This writes the line above to `/output/entry.txt` (creating `/output` if
needed). The program is deterministic — it writes the same line every run —
and uses no network, no input files, and no secrets.
